one-field fix (`bridge_1.length` 6 → 16) changes the outcome under the same frozen controller.
N = 3 per scene is functional-repeatability evidence only, not statistical reliability.

## Limits

- P0 is a scripted, server-side walking controller with privileged knowledge of the route. It
  says nothing about an agent's ability to play.
- The fall on F1-A is expected by construction (walking-only controller, 10-stud hole).
- Positions are server-side and lag the client; area checks use the gap footprint plus a margin.
- In relay mode, the scripts were sent by the operating Claude session from the stored code files;
  the MCP returns no copy of what it ran. The controller echoes its parameters (checked), and the
  build/read-back checks cover the built tree.
